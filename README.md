# BijHommels Website

Static website for BijHommels, built with plain HTML, CSS, and JavaScript.

## GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Select the `main` branch and the repository root as the source.

The contact form opens an email draft. Update `contactEmail` in `script.js` when the final email address is known.
